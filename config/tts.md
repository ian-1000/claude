# TTS (Text-to-Speech) 설정

## 개요
뉴스 브리핑을 자연스러운 음성으로 변환하는 TTS 기능 설정

---

## 사용 기술

| 항목 | 내용 |
|------|------|
| 라이브러리 | edge-tts (Microsoft Edge TTS) |
| 버전 | 7.2.7 |
| 비용 | 무료 |
| API 키 | 불필요 |

---

## 음성 옵션

### 한국어 음성

| 이름 | 음성 ID | 성별 | 특징 | 추천 용도 |
|------|---------|------|------|-----------|
| **sunhi** (기본) | ko-KR-SunHiNeural | 여성 | 차분하고 전문적 | 뉴스 브리핑 |
| injoon | ko-KR-InJoonNeural | 남성 | 차분하고 신뢰감 | 뉴스 브리핑 |
| hyunsu | ko-KR-HyunsuNeural | 남성 | 밝고 친근함 | 일반 안내 |

### 현재 설정
```
음성: sunhi (ko-KR-SunHiNeural)
속도: +0% (기본)
볼륨: +0% (기본)
음높이: +0Hz (기본)
```

---

## 명령어

| 명령어 | 기능 | 출력 |
|--------|------|------|
| `뉴스 읽어줘` | 오늘 브리핑을 TTS로 변환 | MP3 파일 |
| `브리핑 재생` | 생성된 MP3 파일 경로 안내 | 파일 경로 |
| `음성 변경: [sunhi/injoon/hyunsu]` | TTS 음성 변경 | 설정 변경 |

## TTS 변환 과정

```
[뉴스 브리핑 텍스트]
    ↓
[1. 마크다운/이모지 제거]
    - 📌🔗💭 등 이모지 제거
    - **볼드**, *이탤릭* 제거
    - 링크, 테이블 제거
    ↓
[2. 뉴스 스크립트 변환]
    - 음슴체 → 존댓말 변환
    - 섹션별 멘트 추가
    - 인트로/아웃트로 추가
    ↓
[3. edge-tts로 MP3 생성]
    ↓
[briefings/audio/에 저장]
```

## 스크립트 변환 예시

### Before (마크다운 브리핑)
```
📌 2026년 건설업계 핵심 화두: "안전과 AI"
🔗 기사 보기 → https://...
💭 해석 및 배경지식
주요 건설사 신년사의 공통분모는 '안전'임.
```

### After (TTS 스크립트)
```
다음 뉴스입니다.

2026년 건설업계 핵심 화두, 안전과 AI.

해석 및 배경지식입니다.

주요 건설사 신년사의 공통분모는 안전입니다.
```

## 제한 사항

1. **인터넷 필요**: edge-tts는 온라인 서비스이므로 인터넷 연결 필요
2. **긴 텍스트**: 매우 긴 텍스트는 여러 청크로 나눠 처리
3. **특수 기호**: 일부 특수 기호는 잘못 읽힐 수 있음
