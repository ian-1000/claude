# 스마트 알림 규칙

## 알림 우선순위

### 긴급 알림 🔴
즉시 확인이 필요한 뉴스

| 조건 | 예시 |
|------|------|
| AI 규제 정책 변경 | AI 기본법 통과, 생성AI 규제안 |
| 건설업 주요 정책 | 건설업법 개정, 대형 건설사 이슈 |
| 대학원 입시 일정 | 원서 접수, 합격 발표 |

### 중요 알림 🟡
당일 내 확인 권장

| 조건 | 예시 |
|------|------|
| 웹소설 공모전 공고 | 조아라, 네이버, 카카오 공모전 |
| LLM/AI 신기술 발표 | GPT-5, Claude 신버전 |
| 한일 정상회담 | 외교 주요 이벤트 |
| HRD 주요 트렌드 | 기업교육 혁신 사례 |

### 일반 알림 🟢
일일 브리핑에 포함

| 조건 | 예시 |
|------|------|
| 에듀테크 시장 동향 | 투자, 인수합병 |
| 건설 시장 동향 | 수주, 분양 실적 |
| 콘텐츠 산업 뉴스 | IP 사업, 영상화 |

## 알림 표시 형식

### 긴급 알림
```
🔴 [긴급] AI 규제 법안 국회 본회의 통과
→ 즉시 확인 필요

📌 핵심 내용
- {요약}

🔍 이한솔님께 미치는 영향
- {업무/학업/창작 관점 영향}

🔗 기사 보기 → {URL}
```

### 중요 알림
```
🟡 [중요] 네이버시리즈 신인 공모전 공고
→ 오늘 내 확인 권장

📌 핵심 내용
- {요약}

🔍 관련 정보
- 접수 기간: {기간}
- 상금/혜택: {내용}

🔗 자세히 보기 → {URL}
```
