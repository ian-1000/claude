# 일일 다이제스트 설정

## 시간대별 브리핑

### 아침 브리핑 (권장: 07:00-09:00)
**명령어**: `아침 루틴` 또는 `뉴스 검색해줘`

**포함 내용**:
- 전일 주요 뉴스 요약
- 오늘 예정된 주요 이벤트
- 액션 아이템 확인
- 복습할 용어 알림

**형식**:
```
☀️ 좋은 아침입니다, 이한솔님!

📰 어젯밤~오늘 아침 주요 뉴스
{뉴스 요약 3-5개}

📅 오늘의 주요 이벤트
{예정된 이벤트}

✅ 오늘의 액션 아이템
{미완료 액션 목록}

📚 오늘의 복습
{복습 예정 용어}
```

### 점심 브리핑 (권장: 12:00-13:00)
**명령어**: `점심 뉴스`

**포함 내용**:
- 오전 중 주요 뉴스
- 실시간 이슈
- 간략한 시장 동향

### 저녁 브리핑 (권장: 18:00-20:00)
**명령어**: `저녁 루틴`

**포함 내용**:
- 오늘 하루 뉴스 종합
- 오늘 배운 것 정리
- 복습 체크
- 내일 예정 사항

**형식**:
```
🌙 오늘 하루 수고하셨습니다, 이한솔님!

📰 오늘의 뉴스 요약
{주요 뉴스 3-5개}

💡 오늘 배운 것
{새로 학습한 용어/개념}

✅ 완료한 액션
{완료 처리된 항목}

📚 복습 체크
{오늘 복습한 용어}

📅 내일 예정
{내일 주요 일정}
```

## 요일별 특화 섹션

| 요일 | 특화 섹션 | 내용 |
|------|-----------|------|
| 월요일 | 주간 시작 | 이번 주 주요 일정, 지난주 리뷰 |
| 화요일 | 기술 트렌드 | AI/에듀테크 심층 분석 |
| 수요일 | 업무 인사이트 | HRD/조직개발 트렌드 |
| 목요일 | 창작 영감 | 웹소설/콘텐츠 시장 동향 |
| 금요일 | 주간 마무리 | 주간 리뷰, 주말 읽을거리 |
| 토요일 | 학습 집중 | 복습 집중일, 퀴즈 |
| 일요일 | 다음 주 준비 | 다음 주 주요 일정, 목표 점검 |

## 특별 브리핑

### 주간 리포트 (매주 금요일)
**명령어**: `주간 리포트`

**포함 내용**:
- 이번 주 주요 뉴스 TOP 10
- 트렌드 분석
- 학습 현황 요약
- OKR 진행률
- 다음 주 전망

### 월간 리포트 (매월 말일)
**명령어**: `월간 리포트`

**포함 내용**:
- 이번 달 핵심 트렌드
- 학습 성과 분석
- OKR 달성률
- 다음 달 목표 제안

## 브리핑 깊이 설정

### 간략 모드
- 헤드라인 위주
- 시사점 1줄
- 용어 설명 생략

### 표준 모드 (기본값)
- 요약 + 시사점
- 주요 용어 설명
- 액션 아이템 제안

### 상세 모드
- 전체 내용
- 상세 분석
- 배경 설명 포함
- 관련 기사 링크

**모드 변경**: `브리핑 모드: [간략/표준/상세]`

---

## 언어 설정

### 현재 설정
- 메인 언어: 한국어
- 해석 스타일: 음슴체 (~임, ~함)

### 변경 가능
```
해석 스타일: 음슴체
해석 스타일: 존댓말
해석 스타일: 반말
```
