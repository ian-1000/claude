# 뉴스-사용자 매칭 규칙

## 매칭 점수 체계

### 1단계: 키워드 매칭

| 우선순위 | 매칭 유형 | 점수 | 예시 |
|----------|-----------|------|------|
| 최우선 | 회사/핵심업무 직접 언급 | +50 | 자이씨앤에이, GS건설, HRD |
| 높음 | 1순위 관심 분야 | +40 | LLM, 생성AI, 에듀테크 |
| 중상 | 2순위 관심 분야 | +30 | 건설업, 건설경기 |
| 중간 | 3순위 관심 분야 | +20 | 웹소설, 조아라, 네이버시리즈 |
| 기본 | 일반 관심 키워드 | +10 | 한일관계, 대학원 |

## 브리핑 포함 기준

### 점수 기반 선택

| 점수 범위 | 포함 여부 | 표시 위치 |
|-----------|-----------|-----------|
| 70점 이상 | 필수 포함 | 헤드라인 |
| 50-69점 | 포함 | 주요 뉴스 |
| 30-49점 | 조건부 포함 | 관련 뉴스 |

## 시사점 생성 규칙

### 업무 시사점 생성 조건
- HRD/기업교육 관련 뉴스
- AI/에듀테크 기술 발전
- 건설업계 동향 (자이씨앤에이 영향)
- 조직개발 트렌드

### 학업 시사점 생성 조건
- 대학원 관련 뉴스
- AI/데이터사이언스 커리어 동향
- 학위 가치, 취업 시장

### 창작 시사점 생성 조건
- 웹소설 플랫폼 뉴스
- 콘텐츠 시장 동향
- 공모전/신인작가 관련
- IP 사업 동향

### 가정 시사점 생성 조건
- 한일 관계 뉴스
- 일본 관련 정책/문화
- 환율 (엔화)

---

## 제외 규칙

### 항상 제외
- 연예/스포츠 (관심 설정 없음)
- 단순 광고성 기사
- 중복 기사 (첫 번째만 유지)
- 가십성 뉴스

### 주의 필요
- 부정적 뉴스 연속 시 밸런스 고려
- 특정 키워드 과다 노출 방지
