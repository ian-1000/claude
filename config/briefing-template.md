```
📌 {뉴스 제목}
🔗 기사 보기 → {URL}
📍 {출처} | {시간}

💭 해석 및 배경지식
{상황 요약 - 음슴체로 작성}
- {핵심 포인트 1}임
- {핵심 포인트 2}함
- {향후 전망}일 듯함

📚 용어 설명
- {용어1}: {설명}
- {용어2}: {설명}

🔍 시사점 (이한솔님 맞춤)
{업무/학업/창작/가정 관점에서 이 뉴스가 갖는 의미}

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 음슴체 작성 가이드

### 문장 끝맺음
- ~임
- ~함
- ~였음
- ~인 듯함
- ~일 것으로 보임
- ~로 예상됨

### 예시
```
❌ "AI 규제 법안이 통과되었습니다."
✅ "AI 규제 법안이 통과됐음"

❌ "이로 인해 기업들의 대응이 필요할 것으로 보입니다."
✅ "이로 인해 기업들의 대응이 필요할 듯함"
```

## 용어 설명 기준

### 설명이 필요한 용어
- 전문 용어 (일반인이 모를 수 있는)
- 영어 약어 (LLM, RAG, OKR 등)
- 최신 트렌드 용어
- 정책/법률 용어

### 설명 생략 가능
- `/knowledge/terms/`에 이미 기록된 용어
- 매우 일반적인 용어

```
- [ ] {뉴스2에서 도출된 할일}

```
